## Why it matters to me

This is excellent work, may be the key to how to work with AI on a multi-person project.

**Remaining questions:**

- Contrast with the list of issues raised in academic literature. Key categories: AI failures, human skill erosion, quality over time, productivity paradox. Does the model address these, or what needs to be added?
- What metric to use — e.g. DORA. Can we do a case study? Add metrics. Contrast before and after.
- Try to apply this to my own project.
- Understand what the different agent roles are — would it make sense to use an agent platform for them?
- A tension I find problematic: anyone can ask for a feature and it gets implemented with no control. Features can be contradictory. How does the model handle feature governance and prioritization?
